  1. 01

    基于双 LLM Agent 的开放式用户标签挖掘与 Taxonomy 归纳

    主要负责人

    项目背景：针对发票数据信息密度高，探索以大模型 token 换人力，快速挖掘可解释标签并沉淀为可复用的用户标签体系。

    Agent 设计：搭建双 LLM 链路，并以搜一搜补齐陌生公司知识；评测集涌现约 2338 种标签；针对约 171 万开通有发票用户，通过优化搜一搜、prefix_cache 等方法将全量打标由约 10 天压至 4–5 天。

    标签体系归纳：建立「词频统计 → L1-L3 taxonomy → 用户标签长表」的可迭代归纳链路；进一步以数据驱动筛选 HVLR 人群，核心人群 7+ Lift 约 0.14。

    SFT 微调：用 Qwen3.5-27B 对 20 万样本离线推理，归并与分层过采样得到 5 万监督数据，LoRA 对 9B 做结构化 SFT；loss 约 0.13，标签准确性差距 3.8%。

  2. 02

    信贷用户生命周期价值（pLTV）建模与支付长序列表征探索

    参与

    项目背景：信贷 pLTV 需同时刻画借款与违约，两目标在特征空间存在对抗；传统两阶段建模误差叠加，金额侧呈零膨胀与长尾。

    Embedding 特征增强：将宽表字段写成结构化文本输入 Embedding 模型，结合 PLS 降维，Top10% 高价值人群金额误差较原始特征下降 20.5%。

    PZ-Net：针对响应–风控负迁移，设计 PLE+CGC 多专家门控；用 ZILN + Sigma 惩罚处理零膨胀与长尾。响应 AUC 达 0.7982，pLTV 总体误差 11.49%（较 MMoE+ZILN 15.38% 相对降低约 25%）。

    支付表征融合：用 FiLM 按支付情境做特征维调制，经 PLE 非对称分配；验证集响应 AUC 0.7982 → 0.8108，TOP10% 响应占比 39.85% → 41.16%。

  3. 03

    基于 Harness 评测框架与 TextGrad 范式的 Agent 评测体系和可迭代优化闭环

    主要负责人

    项目背景：针对分付规则解释助手 Agent 迭代，引入文本梯度，将「反向传播 + 梯度下降」范式迁移到 LLM 系统优化，自研评测、归因、优化与回归闭环 Skill。

    Harness 建设：建设 261 题离线评测集；设计事实、完整性、个性化、简洁性、合规性五维 Rubric，并通过 Cohen’s κ 校准 LLM Judge；用 Recall@K、MRR 定位故障环节。

    优化与防退化：基于 Prompt vs KB 五类结构化归因，改动绑定源 case；引入 Momentum、回归护栏与发布门禁，关键改动保留四道 Human-in-the-loop 确认。

    项目成果：四轮调优后 κ 达到 0.76，0 分率由约 25% 稳态降至约 3.8%；改动溯源率 100%，单轮迭代由约 2h 降至约 20min；沉淀内网 KM 好文与可交接 Skill。

    TextGradHarness 评测Cohen’s κ Prompt 优化防退化

  4. 04

    基于因果推断与 Uplift 模型的贷中降额策略与连续干预建模

    主要负责人

    项目背景：针对降额管控后违约率不降反升 3.64% 的「降额摆烂」现象，进行因果效应建模，识别降额后的正向作用人群。

    离散干预建模：实验数据采用 Meta-Learner (S/T/X+XGB) + Bagging，并以逾期金额归一化重加权对齐业务目标；观测数据采用 DragonNet，倾向性预估做特征蒸馏，双 outcome 头端到端预估。

    连续干预探索：引入 VCNet，用样条基函数将网络参数建模为干预强度 t 的连续函数，拟合个体剂量-响应曲线，支撑差异化定额。

    项目结果：DragonNet 使管控客群在贷降 3.46%、逾期金额降 13.35%、整体逾期金额占比降 0.38%；VCNet 整体降幅 0.31%，核心价值在连续 Treatment 可建模。

Spec-PINN：基于算子诱导流形嵌入的物理信息神经网络

Physics-informed neural network based on operator-induced manifold embedding for wave propagation and medium inversion

Engineering Applications of Artificial Intelligence (EAAI) · 返修 · 共同一作

针对 PINN 求解高频 Helmholtz 方程时的谱偏差与逆问题周期跳跃， 提出 Spec-PINN：用算子诱导流形嵌入把 Helmholtz 解析性质写入网络结构。

  • 正问题：MFS / Bessel 物理核 + 源项谱通道双嵌入，高波数 k 至 1000 仍保持约 1e-4 相对 L2 误差；
  • 逆问题：渐近多尺度基双网络，将波数搜索转成更稳的权重优化，抑制 cycle-skipping；
  • 非均匀介质反演上，相对 Fourier baseline 参数误差由约 4.76% 降至约 0.36%。
